# Keep My Car - Product Baseline

## Concept

「好きな車に、あと何年乗れる？」

愛着のある車を長期保有したい人向けの、未来型カーライフ・長期保有コストプランナー。

## Target

主に40～70代。特に、愛着のある車を長く所有したい人や、以下の車の所有者。

- 輸入車
- スポーツカー
- 趣味車
- 旧車
- 高額修理リスクのある車

## Product Philosophy

- 車を売るためではなく、長く乗り続けるための資金計画
- 普通の車計簿にはしない
- 故障予測は行わない。故障時期や故障確率をアプリが予測する機能はMVP対象外とする
- 大型修理ストレステストや仮想シナリオは故障予測とは区別し、資金計画のための検討として維持する
- 安心度Score等を乱用しない
- 一人で無理なく長期維持できる製品とする
- 固定費、クラウド費、運用負荷、サポート負荷を小さくする

## MVP Core

- 長期保有コストシミュレーション
- 大型修理への備え
- 愛車修繕積立
- 未来の自分と愛車
- 修理 vs 買替え比較は後工程

## 費目入力

- 費目名称は自由入力とし、「その他」というまとめカテゴリを設けず、各費用を具体的な名称で管理する。
- プリセット候補＋自由入力、車検周期選択、必要に応じた繰り返し／周期登録は、仕様として維持する将来実装対象とする。
- プリセット候補：タイヤ、ブレーキ、バッテリー、オイル、プラグ、サスペンション、エアコン、ブッシュ、電装品、アクセサリー、コーティング、法定12ヶ月点検。
- 車検周期は全ユーザー一律の固定2年とはせず、将来的に必要に応じて選択できる仕様とする。

これらの将来仕様と実装済み範囲は区別する。現在の実装状態は [current_step.md](current_step.md) を参照する。

## Backup / Data Portability

- ユーザーデータの手動Export（エクスポート）と手動Import（インポート）は、MVP全体のMUSTとする。
- 端末故障・紛失への備え、および機種変更時のデータ移行を目的とし、Android → Android、iPhone → iPhone、Android ⇔ iPhoneの移行に対応する。
- 基本方向はローカル保存＋ユーザー操作による手動Export / Importとする。クラウド同期はMVP必須ではなく、このMUSTに含めない。
- MVPは引き続き原則サーバなし、ユーザーアカウントなし、クラウド認証なし、個人情報のサーバ保存なしとし、可能な限りオフラインで利用できるものとする。

MUSTは製品要件であり、実装済みを意味しない。現在の実装状態は [current_step.md](current_step.md) を参照する。

具体的な保存方式・データ形式・利用package、保存DTO構造、schema version、migration方式、export file拡張子、暗号化方式、import時validation、corrupted file対応は永続化設計で決定し、本Baselineでは定めない。

## Technical Baseline

- Flutter
- Dart
- Android / iOS
- 原則ローカル保存
- SQLite等の保存方式の採否は後工程の永続化設計で決定する
- 原則サーバなし
- ユーザーアカウントなし
- クラウド認証なし
- AIはMVP必須ではない
- 重要数値は決定論的Planning EngineがSSOT
